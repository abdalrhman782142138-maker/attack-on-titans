Attack on Titans 2D - Flutter

محتويات المشروع:
- pubspec.yaml
- lib/main.dart
- lib/utils/constants.dart
- lib/game/entities.dart
- lib/ui/game_screen.dart

طريقة التشغيل:
1. فك ضغط الملف.
2. افتح مجلد attack_on_titans_2d في KLENCOD IDE.
3. نفّذ flutter pub get إذا كان متاحًا.
4. شغّل المشروع أو ابنِ APK.

ملاحظة: جُمعت الملفات في ZIP، لكن لم يُختبر البناء فعليًا داخل KLENCOD IDE.
إذا ظهر خطأ، أرسل نص الخطأ كاملًا.
